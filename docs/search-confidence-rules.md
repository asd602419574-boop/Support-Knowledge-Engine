# 检索可信度规则

匹配状态是可解释的规则标签，不是概率，也不表示答案正确率。

- `ambiguous_product`：查询中的启用别名同时属于多个规范产品。返回空结果，由人工解决冲突。
- `insufficient_evidence`：没有页级原文满足检索条件。返回空结果，不补低相关内容。
- `outdated_only`：全部命中均为 `superseded` 或 `archived`。保留结果并显示显著风险提示。
- `version_conflict`：同一规范产品、同一文档类型的新旧状态文档同时命中。要求核对替代关系和日期。
- `high_confidence`：唯一识别规范产品，且至少一个 `effective` 文档页命中。
- `possible_match`：有页级原文命中，但不满足以上更明确的条件。

查询先保留原文，再依次应用 NFKC、英文小写、显式拼写纠正、显式故障同义词、标点和空格清理、产品别名识别。规则来自 `config/query_rules.json`，每次搜索使用的规则保存在 `search_logs.applied_rules`。无法可靠识别产品时不会强制关联。

当前规则不理解复杂语法、否定作用域和隐含上下文；这些问题应进入评测失败清单，而不是添加针对完整问题的答案规则。
