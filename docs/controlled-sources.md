# 受控资料获取边界

资料获取器只读取清单中的 `url` 或 `local_path`。每项必须且只能提供其中一个，`source_id` 必须唯一。程序不解析 HTML、不发现链接、不读取站点地图、不递归目录，也不处理登录或验证码。

URL 获取会检查 2xx 状态、`Content-Type`、`Content-Length` 上限、实际接收长度和 `%PDF-` 签名，并保存最终 URL、ETag、Last-Modified、时间、大小、SHA-256、结果和错误原因。默认超时 10 秒、失败后有限重试 2 次、最大 25 MiB，可通过 CLI 收紧。

`--dry-run` 会读取远程响应以验证真实签名，但不创建下载目录或 PDF 文件。实际文件先写 `.part`，完整校验后原子移动到独立原始获取区。同一 SHA-256 已成功获取时只记重复日志。

清单本身不代表获得授权。启用一项前仍需由用户确认公开许可、网站条款和资料来源。
