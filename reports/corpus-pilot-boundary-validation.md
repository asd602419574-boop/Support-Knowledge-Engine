## 受控获取边界

自动化测试使用本机 `ThreadingHTTPServer`，不依赖外部网络。

| 场景 | 结果 |
|---|---|
| 明确 PDF URL | 校验状态、Content-Type、签名后保存并记录 ETag、大小和哈希 |
| dry-run | 完成远程内容校验，未创建原始下载目录 |
| 相同哈希、不同来源 ID | 第二项记录为 `duplicate`，不重复保存 |
| 同一 URL 内容变化 | 新哈希再次获取并原子替换该来源文件 |
| HTML 伪装 PDF | 记录 `failed`，原因是 Content-Type / 签名不符合 |
| 超大 Content-Length | 在读取正文前拒绝并记录大小限制错误 |
| 404 / 失效 URL | 有限重试后记录 HTTP 错误，不静默跳过 |
| 下载长度不足 | 声明长度与实际长度不符时记录“下载中断” |
| 不安全 source_id | 清单校验阶段拒绝目录穿越字符 |
| 中文本地路径与文件名 | 生成、导入、渲染和检索均通过 |
